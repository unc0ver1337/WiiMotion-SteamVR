# Controller mapping

Right hand: Wii B is trigger, A is grip, D-pad is trackpad direction, 2 is trackpad click and Plus is menu by the initial mapping. Home recenters orientation. Left hand: Nunchuk Z is trigger, C is grip, and the analog stick maps to trackpad x/y. These components use OpenVR input paths; applications still need a SteamVR binding for their actions. The Xbox bridge's button table is not reused.
